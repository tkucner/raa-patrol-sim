# Patrol Unit Simulator

A browser-based teaching simulation of a hybrid human–robot patrol unit (drone, ground robot, sensor mast, operator, commander). Participants configure sensors and patrol routes, adjudicate detection reports, and compare their unit's picture with the ground truth.

- **Play:** open `index.html` (single self-contained file, works offline) or the GitHub Pages site.
- No data leaves the browser; settings are kept in the browser's local storage.
